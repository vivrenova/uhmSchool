# uhm. — демо сайту онлайн-школи

Демо для портфоліо: сторінка курсу вигаданої школи розмовної англійської з тестовою оплатою, листом учню, кабінетом учня й кабінетом власника. Школа, люди, відгуки й оплати — вигадані; це чесно написано на кожній сторінці.

## Що можна потикати

| Сторінка | Що показує |
|---|---|
| `/` | Сторінка курсу: офер, групи й місця, рання ціна з таймером, заняття в Zoom, домашка з правками, програма, викладачка, відгуки-скріни, ціни, FAQ |
| `/checkout` | Бронювання: група, спосіб оплати (повністю / 2 частини / частинами від банку), 2 поля з маскою +380 |
| `/pay` | Тестова платіжна сторінка: картка, Apple Pay (Safari) / Google Pay, код 3-D Secure, відмова банку |
| `/success` | «Оплату отримано», доступ одразу, і що в цей момент отримав власник |
| `/mail` | Лист учню після оплати |
| `/learn` | Кабінет учня: старт, чекліст, програма, платежі, файл календаря з усіма заняттями |
| `/admin` | Кабінет власника: групи, таблиця оплат (CSV), лист очікування, стрічка Telegram-бота — оновлюється в реальному часі |
| `/demo` | Два екрани поруч: телефон учня і кабінет власника |

Кнопка **«Як тикати»** у верхній плашці відкриває демо-панель: закрити набір, залишити одне місце, закінчити ранню ціну через 10 секунд, скинути все.

Тестові картки: `4242 4242 4242 4242` — успіх, `4000 0000 0000 0002` — відмова. Код з SMS — `1234`.

## Як це влаштовано

- **Astro 7** (статичний сайт) + **Preact**-острови лише там, де потрібна інтерактивність. JS на головній — ~30 КБ gzip, решта сторінки — статичний HTML.
- **Дати «ковзні»** (`src/lib/schedule.ts`): старт і дедлайн ранньої ціни рахуються від сьогоднішнього дня за Києвом, тож демо не застаріває.
- **Бекенду немає** (`src/lib/store.ts`, `src/lib/orders.ts`): оплати, лист очікування й сповіщення живуть у `localStorage`, вкладки синхронізуються через `BroadcastChannel`. Для справжнього проєкту міняється лише цей шар: платіжний провайдер (WayForPay / LiqPay / mono), Google Sheets чи CRM, Telegram-бот, розсилка листів.
- **Шрифти**: Fixel (MacPaw) — 3 накреслення, урізані до латиниці й кирилиці; Caveat — для правок «червоною ручкою». Разом ~96 КБ.
- **Фото** — Unsplash, у WebP з `srcset` (див. `CREDITS.md`).

## Де що міняти

- Назва школи, курс, ціни, групи — `src/config/school.ts`
- Ваш підпис і контакти (футер і демо-панель) — `src/config/author.ts`
- Тексти: програма `src/content/program.ts`, відгуки `src/content/reviews.ts`, домашка `src/content/homework.ts`

## Команди

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # статичний сайт у dist/
npm run preview    # перегляд збірки
npm test           # збірка + Playwright: iPhone (WebKit) і десктоп (Chromium)
npm run check      # перевірка типів
```

Перед першим `npm test`: `npx playwright install chromium webkit`.

Допоміжні скрипти для скрінів: `scripts/shots.mjs`, `scripts/states.mjs`, `scripts/flow-shots.mjs`, `scripts/overflow.mjs`.

## Деплой на Cloudflare

Сайт викладається як статичний Worker: конфіг у `wrangler.jsonc` (папка `dist`, сторінка 404), версія Node — у `.node-version`.

1. Cloudflare → Workers & Pages → Create → Import a repository → `vivrenova/uhmSchool`.
2. Project name: `uhmschool` — має збігатися з `name` у `wrangler.jsonc`.
3. Build command: `npm run build`, deploy command: `npx wrangler deploy` (стоять за замовчуванням).
4. Після першого деплою вписати адресу в `site` у `astro.config.mjs`.

Кожен пуш у `main` викладається автоматично, інші гілки отримують превʼю-посилання — зручно показувати клієнтам варіанти.
